    广告写入

    开启后，负责人（总负责人、广告负责人）可以在飞书里让 DeepSeek 按 SparkX 官方写入 Skill 修改广告（出价、预算、状态、否定词、托管组、新建活动等）。 每次修改先列出计划，负责人回复「确认执行」后才执行；定时通知、预览和测试发送始终只读。

    DeepSeek

    API Key 只写不读；测试连接只调用免费的模型列表与余额接口。

    deepseek-flash 速度快、费用低（推荐）；deepseek-v4-pro 推理更强，单价约为 flash 的 3–7 倍。 定时通知在后台运行，每次请求至少等待 180 秒；问答至少等待 90 秒。

    飞书机器人

    由服务器配置开启（FEISHU_BOT_ENABLED）。

    • 群里 @机器人，或私聊机器人，都可以自由聊天；需要数据时 DeepSeek 会自己调用 SparkX 查询。
    • 机器人开始回答时，会先在你的消息上点一个「OK」。
    • 同一段对话会记住最近 6 轮（60 分钟内），可以直接追问「那上周呢」。
    • 群内只回复通知群；私聊限负责人、运营和通知群成员。
    • 默认只能查询。在「SparkX MCP → 广告写入」开启后，负责人可以让机器人修改广告：机器人先列出修改计划，回复「确认执行」后才执行。
