    飞书机器人

    由服务器配置开启（FEISHU_BOT_ENABLED）。

    • 群里 @机器人，或私聊机器人，都可以自由聊天；需要数据时 DeepSeek 会自己调用 SparkX 查询。
    • 同一段对话会记住最近 6 轮（60 分钟内），可以直接追问「那上周呢」。
    • 群内只回复通知群；私聊限负责人、运营和通知群成员。
    • 只能查询，不能修改广告、预算或出价。
