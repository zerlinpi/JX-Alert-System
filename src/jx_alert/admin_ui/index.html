店铺与运营

店铺来自 SparkX Token 授权的 Profile。每家店可指定运营（通知群成员）：未指定时通知照常发到群里，标注「未映射运营」；指定后，这家店出现异常时群消息会 @ 对应运营。关闭监控的店铺不进入任何通知。
