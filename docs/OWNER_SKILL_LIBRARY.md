# 管理员上传自己的 Skills

在管理台打开 **分析设置 → 自定义 Skills 资料库**。选择电脑里的 `SKILL.md` 或单个技能的 ZIP，点击上传。同名技能的新内容成为新版本，初始状态始终是「停用」。点名称预览原文与版本摘要后，可将当前版本标为「可用」。可用仅指文档通过管理员审阅，**不是已应用到模型**。

首次上传可在页面展开「第一次上传？查看文件格式与示例」，复制并另存为 `SKILL.md`。下面是一份带可选分析目标的完整示例：

```markdown
---
name: mature-ad-review
description: 在人工复核广告效率前检查数据是否完整以及归因是否成熟。
metadata:
  jx-review-objective: efficiency
---
# 成熟广告复核
检查币种、报表日期和归因窗口。缺少数据时不要把缺失订单当作零。
```

## 上传一个带参考文件的技能

1. 每个包只放一个技能。将 `SKILL.md` 和可选的 `references/` 一起压缩；也可压缩其父目录，目录名须等于 `name`。不必提供项目清单，不能直接上传整个供应商仓库。例：
   ```text
   daily-review/
     SKILL.md
     references/
       measures.md
       examples/检查表.txt
   ```
2. 在「选择本地技能文档」中选 ZIP 上传。点技能名称，查看主文档、**源文件声明版本**（`metadata.version`，与资料库版本 v1/v2 无关）及参考文档下拉列表。文本、换行和相对路径保持不变；不会渲染原始 HTML、打开链接或执行示例命令。
3. 「导出完整版本 ZIP（含参考文档）」下载所选版本的标准 ZIP，可再导入。为便于复现，归档时间、顺序、权限等元数据会重新生成。只需主文档时仍可用「导出此版本 SKILL.md」。相同文件集合不因压缩方式、顺序或外层目录差异重复建版；任一参考文件内容或路径变化都要求重新审阅。
4. 导出后，**由你选择**是否按目标客户端的规则安装。需要人工粘贴时可从只读预览复制所需文本；需要目录时用导出 ZIP 解开得到技能目录。只证明文档可移植，不代表某模型支持目录导入、已收到上下文、能调用 MCP 或会给出相同分析结果。

## 支持范围与失败后的处理

| 情况 | 处理 |
| --- | --- |
| 主文档 | 遵循 [Agent Skills 格式](https://agentskills.io/specification) 的安全子集：UTF-8，单文件 ≤128 KiB，开头有 YAML 分隔区及非空正文。必填 `name`（≤64 个小写英文字母、数字及分隔用的单个连字符）、`description`（≤1,024 字符）。可选 `license`、`compatibility`、小型纯字符串 `metadata`；纯数字或会被 YAML 当作数值的版本号加引号。复杂嵌套、别名、自定义标签及 `allowed-tools` 一律拒绝。 |
| ZIP 规范 | 仅接收普通未加密存储/Deflate ZIP，≤576 KiB；解压后的文件合计 ≤512 KiB、每份 ≤128 KiB；最多 32 个文档、含目录标记最多 64 项。无需保留空目录。标准 32 位流式描述符可读；分卷、ZIP64、归档注释、自解压前缀、有隐含尾部数据的压缩流或过大的目录索引不支持。 |
| 参考文件 | 仅限 `references/` 及其子目录下的 UTF-8 `.md`、`.txt`。建议用简短可移植的 UTF-8 文件名（字母、文字、数字、空格、连字符、下划线、点）；相对路径 ≤240 字节、≤8 层，每段 ≤100 字节，须 NFC。拒绝绝对路径、穿越、隐藏文件、Windows 设备名、重名/大小写冲突、符号链接与其他特殊文件。macOS 若加入 `__MACOSX/` 或 `.DS_Store`，请仅选所需文档重新打包。 |
| 脚本、模板与素材 | 不支持 `scripts/`、`assets/`、图片/PDF、可执行文件、工具权限字段、连接配置及供应商安装清单。包中出现不支持的内容将**整包拒绝**，不悄悄忽略。若需文档收藏，请另做纯文本副本、改写相关说明，不要把脚本简单改扩展名当作功能已迁移。 |
| 引用其他技能、模型或服务 | 不解析/下载 URL，不跟随目录外引用，不安装兄弟技能，不加载供应商工具或申请权限。详情仅提示常见 Markdown 内联链接里不在该包中的本地 `.md/.txt` 路径（最多 20 处，不是完整依赖分析）。可分别导入其他技能供查阅；这不会连接它们或使远程能力可用。 |

`metadata.jx-review-objective` 可选，只接受 `balanced`、`efficiency`、`reach`、`discovery`。仅对已审阅、可用的当前版本显示本地结构化预览。若要改变已有 JX 广告分析默认策略，请在独立的内置策略面板明确选择。资料库没有模型端点、出站网络访问、远程写入或通知副作用。不要上传密钥或个人数据。

## 版本、存储与回滚

- 每个操作绑定所见资料库版本。详情提供原文、SHA-256、时间、版本列表和最近 30 条审计记录；仅主文件时摘要是其原始 UTF-8 字节的 SHA-256；多文件时是按相对路径排序、以长度分隔的路径和内容的版本摘要。相同内容重试不重复建版。旧版回滚和启停不会删除历史；恢复不同版本后必须重新审阅。最多 32 个技能，每个技能最多 16 个唯一内容版本；到限会拒绝写入，不覆盖旧数据。
- `AGENT_SKILL_LIBRARY_DIR` 默认 `/app/data/owner-skill-library`；空字符串关闭。要求已有的持久化父目录；SQLite 文件由管理台创建在独立的私有目录（POSIX 0700，数据库 0600）。不要指向源码、静态资源、其他 SQLite 文件、网络共享或自动发现技能的目录。上传文件从不写到可导入代码或静态资源路径；没有 MCP 工具、定时任务或运营写入端点。
- 更新前备份持久卷。可先停止 console，然后备份完整资料库目录，再重启；有其他写入方时不要仅复制活动 SQLite 主文件。此版本可只读打开旧资料库（schema 1），首次成功写入时事务性升级为 schema 2；已有原文、指针、摘要、启停及审计保留。旧版未单独记录来源版本，可查看原文。旧代码会拒绝 schema 2：回退服务时先保留完整的升级后目录，再为旧代码配置升级前的独立备份副本；新版本数据仍保存在升级后目录，不会自动降级或合并。不要删卷、覆写或降级活动库。
- 仅所有者 HTTPS 控制台会话可读，写入还需同源、CSRF 和限流。请求体收完并开始保存前会再次验证会话：若已退出或过期则拒绝写入。接口：`GET/POST /console/api/skill-library`，`GET /console/api/skill-library/{name}?version=N`（不传版本即当前），以及仅供所有者下载指定版本的 `GET /console/api/skill-library/{name}/package.zip?version=N`。ZIP 作为附件返回，禁缓存。入库、版本指针、启停状态和审计在同一个 SQLite 事务中提交。审计记录身份为该单所有者管理台账号，不记录正文到日志。

自动验证：`pytest -q tests/test_admin_skill_library*.py`；`node scripts/verify_skill_library_ui.cjs` 验证组件交互（模拟 DOM，不替代浏览器验收）。这些测试使用隔离临时存储，不连接模型、飞书或真实广告系统。

## 可复核的 SparkX 兼容性范围

离线逐文件验证采用 [SparkXAI 官方固定版本的三个查询技能](https://github.com/SparkXAI/SparkXAI-MCP/tree/b72b914b891ad9ed357dd0a36ab0da53152aae85/skills)，不是安装供应商 MCP。仓库只附原创的小型测试包（`tests/fixtures/owner-skills/portable-review/`）与真实测试输入摘要，不转载供应商文档。若已有对应公开 checkout，可在本项目下运行：

```bash
PYTHONPATH=src python scripts/verify_sparkx_skill_packages.py /path/to/SparkXAI-MCP/skills
```

## HTTPS 反向代理的上线检查

现有 Nginx 站点通常限制请求为 64 KiB。这足够普通 MCP，但上述三个官方参考 ZIP 压缩后再使用 JSON/base64 传输分别约为 111、150、68 KB，会在到达管理台前就被拒绝。若管理台启用了 Skills 包，在现有管理台对应的 HTTPS `server` 块添加 [精确路径 location 模板](../deploy/nginx-owner-skill-library.location.example)，仅为 `/console/api/skill-library` 设置 `client_max_body_size 769k`（787,456 字节，与应用请求限制相同），仍路由到私有管理台 `127.0.0.1:8002`。保留现有访问限制与受信代理的真实 IP 解析；模板把已验证的 `$remote_addr` 传给上游，不转发任意客户端提交的 IP 头。若控制台 location 已有额外允许名单或管理鉴权，须等效复制到新增精确路径，不能削弱。不要改变站点 TLS、安全头或普通 `/mcp`/OAuth 请求限制。若控制台已单独被可信 CDN 代理，还要确认该路径的 CDN 请求上限。

上线时先在目标机器备份配置并运行 `nginx -t`，经过批准才重新加载；使用**合成**文档包在已登录控制台经反代验证超过 64 KiB 的合法请求实际到达应用。确认未登录仍被拒绝、超限仍为 413；不要用生产机上的真实客户文档测试。回退时移除新 location、恢复原配置，再验证后重新加载。此模板未改动已有线上代理。
