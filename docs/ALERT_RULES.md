# 异常规则与数据口径

## 日期边界
所有业务日期以店铺 marketplace 时区为准。日报日期 D：前一日为 D-1；基准期为 D-1 至 D-7 共七个完整自然日。当前日不参与基准。缺少任意一天数据时标记样本不足，不把缺失当 0。当前手动广告采集支持传入每个 sid 的站点本地日期映射；自动时区解析尚未实现。

## 销量
默认按店铺 + MSKU（必要时 ASIN）独立计算订单量、件数和销售额。订单变化率 = (D 订单 - 前七日均值) / 前七日均值。默认绝对变化阈值 15%；基准订单均值低于配置下限或基准为 0 时不触发百分比规则，需另行配置零销量恢复规则。**SKU/MSKU 销量数据采集适配器尚未完成**，因此该规则目前只能用测试/外部注入数据验证。

## 广告
当前已接入 SP/SB/SD 活动级日报，字段包括花费（cost）、订单（orders）、销售额（sales）、销量（units）、点击和展示；SP/SD 使用 next_token 游标分页，SB 使用 offset/length 分页。广告活动级数据按 campaign ID 保存。当前尚未接入关键词、广告组、商品广告、ASIN/SKU 商品级报表，也未读取活动日预算和活动状态。

默认高花费阈值 1.30 倍七日均值；无转化需要同时满足最低花费、最低点击、且历史基准有订单；低花费无转化为低优先级观察。预算消耗规则需要活动日预算字段，目前还未接入活动基础资料 API，因此不能在真实采集结果上启用。

广告销售额/订单属于平台归因口径，不等同于领星店铺总销售额；不能将 campaign 花费或订单臆测分配到 SKU。

## 绩效事件
新增绩效通知、账户健康状态变化、政策合规问题应按事件触发，不以七日均值作为唯一判断标准。绩效通知接口尚未确认。

## 通知生命周期
NEW 首次发现；ONGOING 持续；ESCALATED 规则升级；RECOVERED 指标恢复；CLOSED 人工确认关闭。恢复状态只能在完整采集并完成同一实体/规则的检测后产生。数据采集失败或分页不完整时，必须传 `scope_complete=False`，禁止自动恢复。
