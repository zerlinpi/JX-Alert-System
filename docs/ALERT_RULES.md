# 异常规则与数据口径

## 日期边界
所有业务日期以店铺 marketplace 时区为准。日报日期 D：前一日为 D-1；基准期为 D-1 至 D-7 共七个完整自然日。当前日不参与基准。缺少任意一天数据时标记样本不足，不把缺失当 0。

## 销量
默认按店铺 + MSKU（必要时 ASIN）独立计算订单量、件数和销售额。订单变化率 = (D 订单 - 前七日均值) / 前七日均值。默认绝对变化阈值 15%；基准订单均值低于配置下限或基准为 0 时不触发百分比规则，需另行配置零销量恢复规则。

## 广告
活动级与商品级数据分开存储，不把 campaign spend 按比例臆测分配给 SKU。默认高花费阈值 1.30 倍七日均值；无转化需要同时满足最低花费、最低点击、且历史基准有订单；低花费无转化为低优先级观察；预算比例提醒不等同于亚马逊超预算违规。

## 绩效事件
新增绩效通知、账户健康状态变化、政策合规问题应按事件触发，不以七日均值作为唯一判断标准。

## 通知生命周期
NEW 首次发现；ONGOING 持续；ESCALATED 规则升级；RECOVERED 指标恢复；CLOSED 人工确认关闭。恢复状态只能在完整采集并完成同一实体/规则的检测后产生。
