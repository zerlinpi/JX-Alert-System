# 异常通知基准

这是JX的运营提醒门槛，不是亚马逊平台合规线或利润目标。原始数据、15%初筛及日报表格保留，额外门槛只控制业务异常通知和问答中的异常候选。

| 项目 | 普通异常门槛 |
| --- | --- |
| 订单、销量 | 下降至少30%，且至少减少3；参考值至少5 |
| 销售额 | 下降至少30%，且至少减少100美元；参考值至少200美元 |
| 花费增长 | 增加至少40%，且多花30美元，当期至少50美元 |
| 零转化 | 归因成熟后，至少30次点击、50美元花费且明确零订单；连续成熟七日也可按完整窗口合计 |
| CTR | 下降30%，至少下降0.2个百分点，本期与参考期日均曝光至少2000 |
| CPC | 增加30%，至少增加0.25美元 |
| CDR | 下降30%，至少下降2个百分点 |
| CPS、CPA | 增加30%，至少增加5美元；本期与参考期日均归因销量/订单至少3 |
| ROAS | 下降30%，至少下降0.5倍 |
| TCOAS | 增加30%，至少增加5个百分点；店铺销售额至少200美元 |

除CTR以外的比率还要求本期与参考期日均至少30次点击、50美元花费。仅使用完整、同对象、同币种的证据；金额门槛仅适用于明确USD数据。CDR/CPS/CPA/ROAS遵守原SP7日、SB/SD14日成熟归因保护；店铺混合广告沿用保守14日口径。未知、失败、无记录、分母为零不判正常，也不补零。

参考优先前七个完整日期；不足时只使用精确前一日。普通异常需连续两个真实报表日期达到门槛，不以重复采集次数充当持续时间。严重异常（恶化至少50%、绝对变化至少普通门槛两倍；花费增长至少80%）可单日提示。零转化达到独立门槛后可提示。仅消耗90%预算不提醒；源记录超预算事件还需已观测日预算的120%及至少30美元超额。未知预算类型不硬判超额。

同对象、问题及报表日沿用现有去重；规则事件持续时保持静默。初次轻微、后来达到实质门槛的持续事件可首次通知。未通知过的轻微事件不单独发送恢复消息。权限、数据质量和账户源状态保护独立保留；健康继续仅观测归档。

`alert_materiality_enabled` 默认false以兼容旧运行配置。审核并同步所有读取运行配置的服务代码后，在私有 `data/runtime-settings.json` 设置true启用；先备份该文件。回滚旧代码前恢复对应配置备份，旧版本不接受新增字段。无需数据库迁移，不修改.env或广告设置，不重放历史失败通知。

DeepSeek只解释冻结证据与复核建议，不能绕过服务端的Chat提交、KPI提交及规则通知门槛，也不能执行广告修改。样本筛选不代表已完成全活动巡检。未进行人工标注前，不宣称误报率已验收。
