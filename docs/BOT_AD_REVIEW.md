# 机器人按问题分析广告

群内真正@机器人或已授权成员私聊时，可以直接问：

> 有哪些店铺的广告情况存在异常情况，只发送当前能看见的数据的店铺的异常广告记录，数据不全，或者缺少成熟归因数据的内容不显示

此类问题在店铺清单、数值查询和固定日报分支之前，进入DeepSeek广告分析。保留运营原话，让模型选取相关的实质问题并解释；不会附带绩效快报、正常店铺、数据缺口或成熟等待清单。单店、模糊店铺名、多个品牌和当前运营店铺范围沿用既有读取授权，未匹配的具体品牌不扩大为全部店铺。

## 数据权限和证据

DeepSeek可以读取本次问题范围内的广告事实和比较证据，不能调用写工具、任意SQL、外部URL或更改广告、预算、竞价、库存及店铺设置。私聊实时采集仍使用既有独立授权流程，不由模型执行。回答沿用原始提问会话，不主动广播到其他群。

默认只分析SP。明确询问SB/SD时才纳入对应类型。统计日、完整日流量和成熟转化日分别保留；SP归因等待7日，SB/SD为14日。完整前七日基线不足时，仅允许完整精确前一日，不补零。

进入分析的活动须同时满足授权范围、完整报表分区与源记录数、关键事实及同源USD，并能在最新同日原始快照中逐项复核。原始采集和覆盖完成时间必须达到该统计日结束加归因等待期限；不能仅因日期已过去就把旧观测当成成熟数据。MCP流量观察缺少归因订单、销售额时不与API事实拼接成完整转化证据。

实质变化候选继续使用现有materiality基准，过滤小样本、小波动及改善；它是模型复核的输入，模型仍须根据用户问题决定要列哪些活动。不会仅因花费增加就认定浪费，也不能凭这些输入断言断货、浪费搜索词或超预算。

## 输出和可靠性

模型只返回本次证据中的活动编号、受支持的恶化信号和简短中文分析。服务端核对编号、信号及文本，由源事实渲染金额、订单、指标、基准与实际日期；拒绝凭空金额、正常/改善冒充异常、缺口模板及无证据断言。近期CTR/CPC/花费使用对应报表日，转化项使用成熟日。活动暂停时不称现在仍在消耗。

每批最多12个实质候选，处理所有批次，不只取高花费前几条冒充全量。完整证据指纹用于10分钟同成员、同会话缓存；新事实、权限或覆盖变化使缓存失效。模型分析后重新核对证据和会话权限，再进入既有提问回复队列。入队不等于实际送达。

无可列出的结果时，仅回复本次筛选范围内没有需列出的异常记录，不声称所有店铺广告正常；模型或证据核对失败则说明本次分析未完成。结果按短卡片合并，避免宽表溢出及逐活动大量发消息。

本流程只响应成员提问，不改变08:00日报、自动异常规则、静默通知政策或后台同步行为。
